# Claude Code handoff — AGI Map

Fastest workflow:

1. Put these instruction files in the root of your existing repository.
2. Open Claude Code in that repository.
3. Paste the entire contents of `CLAUDE_MASTER_PROMPT.md` as your instruction.
4. Tell Claude Code that `CONTENT_SPEC.md`, `DESIGN_SYSTEM.md`, `SOURCES.md`, and `ACCEPTANCE_CHECKLIST.md` are authoritative support files.
5. When it finishes, double-click `index.html`.
6. Run through `ACCEPTANCE_CHECKLIST.md`.

The master prompt is intentionally prescriptive because this project is time-sensitive.
